# Sample conversations to drop in Meetings

Eleven synthetic sales conversations between an Orbita CRM account executive and a buyer, in the formats real tools export. Drop a file in **Meetings › Add a meeting** (or paste its text in **Paste text**). Leave **Select your opportunity** on *Detect it from the transcript*: the agent finds the opportunity on its own.

They are generated by `node scripts/build_data.mjs` from the kit's meetings, and each one reads back to exactly the conversation the eval scores. Offline (no Claude key), these are the only conversations with a saved result; with the Orbita server and a key, any transcript works.

| File | Format (like) | What it shows |
|---|---|---|
| `acme-logistics_discovery-call.vtt` | WebVTT with voices (Microsoft Teams) | A complete discovery call: every MEDDPICC element, stage Qualified Opportunity → Solution |
| `verde-retail_intro-call.txt` | Timestamped lines (Granola, Fathom) | An intro with no date: due date and stage stay empty, "No budget allocated" |
| `nimbus-health_demo-planning.txt` | Otter export (`Name  0:14`, then the text) | The approved demo is cancelled: Keep, Replace or Clear |
| `verde-retail_pos-data-questions.vtt` | WebVTT with "Name: text" cues (Zoom) | A recording cut mid-sentence: blocked until you confirm the meeting ended there |
| `delta-pharma_intro-call.vtt` | WebVTT (Teams) | A company that is not in the CRM: a new client and opportunity are proposed |
| `atlas-manufacturing_proposal-check-in.srt` | Subtitles (SRT) | "Let's sign" from someone who does not sign: the stage does not move; "one million deal" ignored |
| `cedro-construtora_discovery-call.txt` | Plain "Name: text" lines (copy and paste) | A clean call to try the seller's edit |
| `horizonte-foods_solution-walkthrough.vtt` | WebVTT (Zoom) | Another seller's opportunity (Lucas Moreira): blocked for Ana, nothing shown |
| `lumen-education_scope-session.vtt` | WebVTT (Teams) | A scope session: seats, departments, integrations; Solution → Proposal |
| `pampa-agro_discovery-call.txt` | Timestamped lines with "Speaker 2" | Voices the notetaker could not name: no economic buyer, no champion |
| `WhatsApp Chat with Henrique Prado.txt` | WhatsApp "Export chat" (without media) | Terms agreed in writing: Negotiation → Contract, "tomorrow" read from the message date |

## Your own transcripts
- **Teams**: in the meeting recap, Transcript › Download as .vtt.
- **Zoom**: cloud recording › Audio transcript (.vtt).
- **Google Meet**: the transcript document; copy its text and paste it.
- **Granola, Otter, Fathom**: export or copy the transcript as text.
- **WhatsApp**: open the chat › More › Export chat › Without media; drop the .txt.
